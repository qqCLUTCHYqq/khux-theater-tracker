Contents and sources

The ZIP contains only installer code, launchers, checksum metadata, instructions, and the existing editor guide. No copyrighted game files or browser binaries are bundled. Game downloads use the original Internet Archive collection and its own replicas. Google Chrome is downloaded from Google's official Chrome for Testing HTTPS manifest/storage. No game files were rehosted.

Game SHA256 pins were computed from files matching the Archive's published SHA1 references; the Archive did not provide an independent SHA256. Google's manifest has no SHA256; its ZIP is checked against its HTTPS storage MD5 header when present.

Use and rollback

Extract the whole ZIP and run START SETUP.vbs (or START SETUP.cmd). Close any older installer first. On first launch, select the Content folder when the game asks. Leave GameProfile intact and do not clear browser storage.

The original public installer is preserved exactly as KHUX-Windows-Setup-Legacy.zip. Rollback means restoring the setup helper; do not remove or overwrite your installed game/profile to roll back. The older helper lacks the new resume/protection features.

Allow 10 GB free for downloads/extraction. A complete verified installation does not need that reserve. Resume/quarantine files are retained and can consume additional space. This unofficial preservation helper is not affiliated with Square Enix or Disney.
