Install

  1. Extract the whole ZIP and run START SETUP.cmd.
  2. Follow the four steps. Pause safely and rerun to resume.
  3. Click Launch Game. For the first import, click Copy Content folder path, choose Game folder / Choose Files in the game, paste the path in the picker's address bar, select the Content folder and confirm.
  4. Wait for import. Later, use the same desktop shortcut and Start when shown.
