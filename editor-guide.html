Game speed & save editor guide

For the Worldwide 5.0.1 browser preservation build. These controls edit the running Dark Road game and its save data. They are separate from your Theater Tracker checkboxes and from the patches bundled with Content.

Start here

  1. Import Content, start the game, then enter Dark Road and load or create a save.
  2. Open the page's Save data panel. Click Refresh once the game has loaded. Blank, disabled fields mean that part of the game's data is not loaded; they do not mean zero.
  3. Before experimenting, close the game and its Chrome windows and copy the whole GameProfile folder somewhere safe. Reopen the game afterward. The Windows installer stores it at %LOCALAPPDATA%\KHUX-Preservation\GameProfile. Earlier manual installations keep GameProfile alongside Content and v1.
  4. Record the original value. Change one field at a time, click Set, and check the result in game.
  5. For changes you want to retain, click Write save file, read the result message, and verify them after reopening the game. Live-only state and keep locks are not guaranteed to persist.

Your screenshots show “no save data yet — start a game and load a save.” Load Dark Road first; the editor cannot change an unavailable save.

Buttons and game speed

Speed
Changes the engine's time scale from 0.25× to 8×, in 0.25 steps. 1× is normal; below 1× is slower, above 1× is faster. It does not change your character's level or stats. Do not assume prerecorded movies or audio will accelerate in sync; return to 1× for story viewing.
Set / Enter
Writes the number in that row to the running game. With keep unchecked, this is a one-time change: gameplay may subsequently change or recalculate it. Simply typing a number does not apply it.
keep
Checking this immediately applies the typed value and locks it by rewriting it every frame. For example, a locked resource can be restored after spending. Unchecking stops the rewriting; it does not restore the original value. To undo an edit, uncheck keep, re-enter the original value and press Set. Locks belong to the running engine; do not rely on them surviving a restart.
Unlock
The button beside Next boss stage sets that field to 119 and checks keep. The build labels 119 as “theatre.” This is a progression override, not a guarantee that every story flag, reward or tutorial is completed. Back up first; uncheck keep before trying to progress normally.
Refresh
Reads current values from the running game into the panel. It does not reload the whole game or restore a backup. A field being actively edited may keep its typed text until you leave it.
Write save file
Calls the game's save writer for s1200.gif and flushes the browser-backed saved files. Despite its extension, this is game save data. This button is not a download/export backup. Read the status message: the writer can report failure or that no file was written. Keep your browser profile backup.

Dark Road · asset

BP
The BP balance. BP is used for leveling and, in offline Dark Road, shop purchases. For example, setting 10000 writes a balance of 10000, rather than adding 10000 to the existing balance. Keep freezes that balance while active.
Key 1 / Key 2
Two separate saved key counters. The editor code does not identify which is the normal versus premium quest key. Do not assume the numbering matches a particular item: compare each with your in-game inventory before changing it. Editing a count does not recreate unavailable event quests.
Draw tickets
The saved card-draw-ticket counter from the online-era draw system. Offline Dark Road uses BP purchases instead. Increasing this field does not restore the old draw system and may have no useful effect in this release.
Amulets
The asset counter named “amulet” by the editor. Dark Road has revival items known as Charms, but the mapping of this editor field to that inventory item has not been independently tested here. Confirm the displayed inventory count before using it.
Shop points
The old shop-points counter. It is not BP. Offline shop purchases use BP, so changing this legacy field does not enable the old shop-point system.

Dark Road · status

These are direct edits to saved status values, not normal level-up actions. The game may recalculate them. Setting Level alone does not guarantee that the other stats, unlocks or rewards will be recalculated as if you earned that level.

Level
The saved character level.
HP
The HP stat in the saved status block. This is not confirmed to be the separate current battle-health value; do not treat keep on this field as guaranteed invincibility.
Attack
The physical attack stat, affecting physical damage alongside the game's other combat calculations.
Defense
The physical defense stat, used in physical-damage mitigation.
Magic
The magic stat, used for magical attacks.
Resist magic
The magic-resistance stat, used in magical-damage mitigation.

Dark Road · stage

Next boss stage (119 = theatre)
The saved next-open progression ID. The editor provides 119 as its Theatre preset. This is an internal ID, not a Theater Tracker entry number or a documented list of chapter numbers. Other IDs have not been mapped in this guide.
Fallback stage
A second saved progression ID named fallbackOpenId. Its exact selection conditions are not documented in the editor. Leave it unchanged unless you have a known-good value and a backup; do not copy the 119 preset into this field.

Dark Road · tutorial

These are internal tutorial-state fields. The editor exposes the raw numbers but does not document a complete “skip tutorial” recipe. Changing only one can leave related state inconsistent. Playing through the tutorial normally is the dependable option.

Tutorial phase
The tutorial's phase/progress value. The meanings of individual phase numbers are not mapped here.
Tutorial jewels
A jewel-related value inside the tutorial record. It is not confirmed to be a spendable general jewel balance, and it does not restore online currency features.
Tutorial finished
A one-byte tutorial-completion field. Its exact valid game values and required companion flags are not confirmed; do not assume that setting 1 safely completes the tutorial.
Tutorial popup
A one-byte tutorial-popup state field. The editor does not document what each value means. This is not a general-purpose “hide all popups” setting.

Dark Road · theatre

Theatre gate (live)
Edits a live-memory Theatre-related value, unlike the fields addressed through save sections. Its exact value meanings and persistence are not documented. Do not assume it is a simple 0/1 toggle or that Write save file saves it. It is separate from the 119 preset above and does not restore Union χ gameplay.

Values, troubleshooting & undo

  • Use whole numbers and modest changes. The editor's integer limits are storage limits, not safe gameplay limits. It truncates fractions and clamps values; it does not validate a sensible level, stage or currency amount.
  • If a value changes back, the game may have recalculated it. Keep forces it while active, but forcing progression/tutorial fields can interfere with normal play.
  • If something looks wrong, uncheck keep and restore the recorded original value. A field edit cannot undo other events the game has already triggered; use a backup for a full rollback.
  • To restore a profile backup, close all game Chrome windows, retain a copy of the current profile, then put the backed-up GameProfile back at its original location. Do not merge a running profile.
  • Clear Storage is not undo. It removes browser-stored game data. Do not use it to reverse one editor change.

Bundled patches are separate

The preservation archive also contains patches changing title-screen version text, increasing level-stat bonuses by 40%, and changing enemy-kill bonus requirements. These are Content files, not toggles in this editor. The panel does not provide an on/off switch for them.

Dark Road is playable. Union χ remains offline Theater Mode/avatar customization.

How this guide was checked

Set, keep, Unlock, Refresh, save-writing, speed range and field layout were checked against the JavaScript embedded in the downloaded preservation release. Gameplay effects of every field have not been tested. Unmapped fields are explicitly marked rather than supplied with guessed values.

Background: Square Enix offline-mode announcement, Dark Road gameplay and offline changes, and currency reference.
